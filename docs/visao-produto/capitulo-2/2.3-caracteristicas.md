# 2.3 Características do Produto

## Matriz de Características do Produto

### Instrucoes para a Redacao
A equipe deve mapear nesta secao as caracteristicas de alto nivel (*features*) planejadas para o sistema DUOC Finance, estabelecendo a rastreabilidade direta com os Objetivos Especificos (OE1 a OE4) definidos no projeto. Preencha a tabela matricial abaixo delimitando com clareza o escopo das capacidades CAR-01 a CAR-04 (e caracteristicas adicionais, se aplicavel).

### Perguntas Norteadoras
1. De que maneira a caracteristica resolve diretamente a dor operacional de fragmentacao ou retrabalho identificada no Capitulo 1?
2. A qual Objetivo Especifico Principal a caracteristica responde prioritariamente?
3. Qual objetivo secundario se beneficia indiretamente da implementacao dessa funcionalidade?
4. Qual e o indicador de valor de negocio gerado para a DUOC com a entrega desta capacidade?

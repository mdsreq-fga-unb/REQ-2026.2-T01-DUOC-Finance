# Capítulo 8: Requisitos de Software

!!! info "Artefato Previsto para a Unidade 2"
    Esta seção descreve os requisitos funcionais e não funcionais necessários para o desenvolvimento do software **DUOC Finance**. Conforme o planejamento pedagógico da disciplina e o cronograma da equipe, este artefato será formalizado e entregue ao longo da **Unidade 2**.

---

## Estrutura Prevista

1. **8.1 Lista de Requisitos Funcionais (RF):** Funcionalidades específicas que o sistema deve implementar (autenticação, registro de RVT, apuração de folha, controle de despesas e relatórios).
2. **8.2 Lista de Requisitos Não Funcionais (RNF):** Qualidades e restrições do sistema estruturadas sob o modelo **FURPS+** (usabilidade, confiabilidade, desempenho, suporte e segurança/LGPD).
3. **8.3 Matriz-Síntese de Rastreabilidade:** Rastreabilidade bidirecional entre requisitos funcionais, objetivos específicos e casos de teste.

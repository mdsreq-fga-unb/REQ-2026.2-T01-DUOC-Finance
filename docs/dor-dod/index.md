# Capítulo 9: Definition of Ready (DoR) e Definition of Done (DoD)

!!! info "Artefato Previsto para a Unidade 2"
    Esta seção estabelece os acordos de trabalho e critérios formais que definem quando um requisito está pronto para ser desenvolvido (*Definition of Ready*) e quando uma funcionalidade está formalmente concluída (*Definition of Done*). Conforme o planejamento pedagógico, este artefato será consolidado na **Unidade 2**.

---

## Estrutura Prevista

1. **9.1 Definition of Ready (DoR):** Critérios prévios de completude, clareza, especificações BDD e protótipos homologados no Figma.
2. **9.2 Definition of Done (DoD):** Critérios de aceitação técnica (código tipado, cobertura de testes automatizados, revisão de PR, documentação no MkDocs e homologação com a cliente).

# 5.2 Mapeamento de Engenharia de Requisitos ao Processo

## Integração entre as Fases do Processo e a Engenharia de Requisitos

### Instrucoes para a Redacao
A equipe deve mapear na tabela estruturada abaixo como as atividades classicas de Engenharia de Requisitos estao distribuidas entre as fases e sprints do ciclo de desenvolvimento do DUOC Finance, detalhando as praticas ageis, tecnicas aplicadas e os artefatos de entrega gerados.

### Perguntas Norteadoras
1. De que forma as atividades de ER se distribuem de maneira continua ao longo das sprints, em vez de ficarem restritas a uma fase inicial?
2. Quais praticas do Scrum e do XP servem de veiculo para a realizacao das tecnicas de requisitos em cada ciclo?
3. Quais sao os produtos concretos (documentos, prototipos ou modulos de codigo) resultantes de cada etapa?
